## 技术与一致性

### 保存

客户端创建 UUID，重复创建复用该 ID。更新携带服务端版本与独立变更 ID；成功回复按变更 ID 记录，重试不重复保存。其他设备已修改时返回 `VERSION_CONFLICT` 和当前版本。已删除内容返回 `DELETED`，不自动复活。

800ms 写入账号隔离 IndexedDB，2s 尝试服务端保存。只有成功回执后显示“已保存到服务端”。SQLite 位于本机时不声称已经部署到云端。退出优先同步；未同步时明确提示导出再退出，随后清除该账号缓存。

当前整条想法用 JSON 字段保存正文、整理和行动，统一版本控制；跨设备合并提供正文拼接，其余字段由用户明确选择使用本地版或云端版。高并发或更复杂的协作需要拆分实体与更细粒度版本。

### AI 请求与结算

服务端先生成短时有效的额度报价，绑定最终上下文、版本、模型、费率与最大输出。确认发送时再次验证状态、权限、版本和余额，并在 `BEGIN IMMEDIATE` 事务中插入任务及预占流水。数据库部分唯一索引阻止同账号同时运行多项任务。

AI 网关按 SSE 读取供应商文本并持久化增量；客户端当前每 550ms 读取消息快照，实现渐进显示和重连恢复。刷新页面不会重新发送。此版本尚未实现客户端 SSE 通道与消息序号分页。

完成或有可信用量的主动停止按实际扣点且不超过上限；供应商错误、拒绝、超时、无输出停止、整理格式错误不扣点。没有可信 usage 的调用由平台承担并立即释放，不进行事后追扣。每条请求的流水种类有唯一约束，重复终态不能重复扣费。服务启动恢复未完成请求为失败并释放预占。

当前历史超预算会只发送最近能容纳的对话，并在发送前明确提示；不会截断当前问题与原始记录，没有伪称使用未发送的完整历史。历史摘要属于后续实现。

### 安全边界

- 所有用户对象以服务端会话的 user ID 查询与变更，忽略客户端的归属字段。
- 会话为随机令牌，数据库只存哈希，Cookie 为 HttpOnly / SameSite Strict；生产模式使用 Secure。
- 状态改变请求要求同源检查与专用请求头，OTP 与 AI 有服务端限流。
- AI 输出按 React 纯文本渲染，不解释 HTML、脚本、外部图片或危险 Markdown 链接。
- Service Worker 只缓存同源静态资源；私有 API 设置 `Cache-Control: no-store`。
- SQLite 文件默认未加密。数据库、备份、部署机权限、HTTPS、管理强认证需要正式部署方案。
- 后台仅返回元数据。模型密钥、正文、验证码不写入应用日志。
